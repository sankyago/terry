# Cruise — інтерактивні білети ПДР

Веб-тренажер, у якому **ви керуєте рішеннями, а не машиною**. Авто саме їде маршрутом містом (камера згори під
45°). Коли воно зупиняється перед ситуацією, світ стає на паузу й з'являється білет: питання та 3 варіанти. Після
правильної відповіді авто діє правильно й їде далі; після неправильної — виконує обраний варіант, і ви бачите
анімацію ДТП (удар, уламки, дим, аварійка), а потім пояснення.

> Навчальний тренажер. Ситуації спрощені, пункти ПДР вказано для довідки — звіряйтеся з чинною редакцією.

## Запуск

Потрібен Node.js 20+ (перевірено на 22).

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit-тести (Vitest)
npm run typecheck  # перевірка типів
npm run build      # продакшн-збірка в dist/
npm run preview    # перегляд зібраної версії
```

Щоб відкрити з телефона в тій самій мережі: `npm run dev -- --host` і перейти за IP-адресою комп'ютера.

Збірка використовує відносний `base: './'`, тож `dist/` можна викласти на будь-який статичний хостинг.

### GitHub Pages

`npm run deploy:pages` проганяє тести, збирає застосунок і публікує `dist/` у гілку `gh-pages`.
У налаштуваннях репозиторію: **Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`**.

Для автоматичного деплою при кожному пуші в `main` скопіюйте `scripts/github-pages-workflow.yml` у
`.github/workflows/pages.yml`: workflow проганяє тести, збирає застосунок і публікує `dist/` у `gh-pages` —
налаштування Pages міняти не треба. Запустити вручну: Actions → Deploy to GitHub Pages → Run workflow.

## Режими

- **Навчання** — пояснення й пункт ПДР після кожної відповіді. Після ДТП можна «Переграти ситуацію» (повтор не
  впливає на оцінку) або «Показати правильно й далі».
- **Іспит** — без пояснень до кінця маршруту, ДТП так само показується. Складено, якщо помилок не більше 1
  (авторський критерій). У результатах — розбір кожної помилки.

## Керування

| Дія | Клавіші / жест |
| --- | --- |
| Відповідь | клік / дотик або `1`–`3` |
| Далі після ДТП | `Enter` |
| Камера «за авто» / «північ угорі» | `C` або кнопка |
| Пауза | `Esc` або кнопка |

На паузі ситуації учасники підсвічені пульсуючим кільцем зі стрілкою напрямку, а білі шеврони показують
намічений рух вашого авто. На широкому екрані білет праворуч (кадр зсувається вліво), на вузькому — знизу.

## Як це влаштовано

- Симуляція (`src/sim/`) детермінована й не залежить від Babylon/DOM. Автопілот плавно гальмує до стоп-лінії
  кожної ситуації й зважає на повороти.
- Учасники ситуації з'являються, коли авто рушає до неї; їхній старт розраховано так, щоб у момент рішення вони
  були точно на заданій відстані від точки конфлікту.
- Неправильна відповідь: авто рушає, а учасник приходить у точку конфлікту одночасно з ним — ДТП гарантоване.
  Удар — імпульс з урахуванням мас (автобус майже не зрушує, легковик розвертає), далі ковзання з тертям.
- У момент рішення робиться знімок стану (`snapshot`), тож ситуацію можна переграти або показати правильний варіант.
- `tests/tickets.test.ts` проганяє всі білети: кожна неправильна відповідь → ДТП, правильна → без ДТП.

## Структура

```
src/
  config.ts            константи авто (Audi A5 Coupé 2012), автопілота, міста
  tickets/tickets.ts   маршрут і всі білети: питання, варіанти, пояснення, учасники, світлофори
  sim/                 чиста симуляція: path, city, sim (автопілот, учасники, ДТП), collision
  scene/               процедурне місто, транспорт, пішоходи, ефекти ДТП, підказки
  camera/CameraRig.ts  камера згори під 45°, фокус на ситуації, трясіння при ударі
  game/Game.ts         фіксований крок 60 Гц, статуси, події для UI
  audio/AudioEngine.ts синтезований звук: двигун, сирена, удар
  storage/storage.ts   налаштування й прогрес у localStorage
  ui/                  React: старт, HUD, білет, ДТП, результати, пауза
```

Параметр `?debug` в адресі відкриває об'єкт гри як `window.__cruise` — для автоматичних перевірок.

## Відомі обмеження

- Сім фіксованих ситуацій на одному маршруті; порядок не перемішується.
- Фізика удару спрощена (2D-імпульс і тертя), без деформацій кузова.
- Перехожі на тротуарах — лише для атмосфери, у симуляції не беруть участі.
- Продуктивність на реальних телефонах ще не виміряно.
